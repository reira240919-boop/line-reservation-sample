# LINE予約管理（サンプル）

LINE から空いている日時を選んで予約できる、予約管理ツールのサンプルです。
実際に運用しているツールから、依頼者に関わる情報を取り除いて公開しています。

## できること

### 予約する人（LINE の中で操作）

- 公式LINEのメニューから予約ページを開き、空いている日時を選んで予約する
- 予約が確定すると、確認メッセージが LINE に届く
- 予約日の前に、お知らせが LINE に自動で届く
- 届いたリンクから、日程の変更やキャンセルができる

### 管理する人（Web の管理画面）

- 予約の一覧を見る、キャンセルする、メモを残す
- 曜日ごとの受付時間を設定する
- 休みの日や時間帯を設定する
- LINE で送るメッセージの文面を編集する
- 予約が入ったときに、管理者の LINE に通知が届く

## 使っている技術

| 役割 | 技術 |
|---|---|
| 画面（予約・管理） | Next.js（App Router） |
| データベース | Supabase（PostgreSQL） |
| LINE の中で開く予約ページ | LIFF |
| LINE への通知 | LINE Messaging API |
| 公開先・毎朝の自動送信 | Vercel（Cron） |

## 動かし方

1. パッケージを入れる

   ```bash
   npm install
   ```

2. `.env.example` をコピーして `.env.local` を作り、自分の Supabase と LINE の値を入れる

3. データベースのテーブルを作る（中身は `supabase/schema.sql`）

   ```bash
   npm run db:apply-schema
   ```

4. 起動する

   ```bash
   npm run dev
   ```

   http://localhost:3000 を開くと、管理画面のログイン画面が表示されます。

## 注意

- このリポジトリには、本物の鍵・予約データ・依頼者の情報は入っていません。
- `.env.local` は公開しないでください（`.gitignore` で除外しています）。
